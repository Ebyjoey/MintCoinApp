# MintCoinApp
# Mintcoin App - A Web3 Blockchain-based Cryptocurrency

## Overview
Mintcoin is a decentralized cryptocurrency built on a Web3 blockchain. This app allows users to mint, send, and receive Mintcoin through a secure blockchain-based network. It uses smart contracts to ensure secure transactions.

### Features:
- **Minting**: Users can mint new Mintcoins by interacting with the blockchain.
- **Sending & Receiving Coins**: Send or receive Mintcoins to/from other wallets.
- **Web3 Integration**: Built using the Web3 technology to interact with Ethereum-based blockchains.

## Installation & Setup

### Prerequisites
1. **Java Runtime Environment (JRE)**:
   Since this is a Java-based application, you'll need to have the JRE installed on your machine.

   - Download Java from [Oracle's official site](https://www.oracle.com/java/technologies/javase-jre8-downloads.html).

2. **Web3 Provider**:
   Ensure you have a Web3-compatible provider (like Metamask or a node) to interact with the blockchain.

### Running the Application

#### 1. **Using the `.jar` file**:
   - Download the `MintcoinApp.jar` from this repository.
   - Open your terminal and run:
     ```bash
     java -jar MintcoinApp.jar
     ```

#### 2. **Using the `.jnlp` file**:
   - Download the `MintcoinApp.jnlp` file from this repository.
   - Open it with Java Web Start (or any other compatible JNLP viewer).

### Interacting with the Blockchain

1. Set up a Web3 provider like **MetaMask** or configure a local Ethereum node.
2. Connect to the Ethereum network or a testnet (e.g., Rinkeby or Ropsten).
3. Ensure you have some test Ether (ETH) or Mintcoin tokens to interact with the blockchain.

## Troubleshooting
- If you experience issues running the `.jar` or `.jnlp` file, make sure your JRE version is up to date.
- Ensure that your Web3 provider is properly configured to communicate with the blockchain.
